# Phase 8: Generative AI（第 8 阶段：生成式 AI）

> 创建图像、视频、音频、3D 等。

## Start this phase on GitHub（在 GitHub 上开始本阶段）

**Prerequisites（先修条件）：** Phase 2 ML Fundamentals（第 2 阶段 机器学习基础）, Phase 3 Deep Learning Core（第 3 阶段 深度学习核心）, and（以及）Phase 7 Lesson 14, Build a Transformer from Scratch（第 7 阶段第 14 课 从零构建 Transformer）。

**First lesson（第一课）：** [Generative Model Taxonomy and History](01-generative-models-taxonomy-history/)（生成模型分类与历史）

Run this command from the repository root（从仓库根目录运行此命令）：

```bash
python3 phases/08-generative-ai/01-generative-models-taxonomy-history/code/main.py
```

Keep the command, exit code, density estimates, generated samples, and one sentence explaining what an implicit generator cannot answer about `p(x)`.

**Next action（下一步）：** Change the random seed, compare the density estimates, then continue to [Autoencoders and VAE](02-autoencoders-vae/)（改变随机种子，比较密度估计，然后继续到自编码器和 VAE）。

Browse the [full Phase 8 lesson list](../../README.md#phase-8) or the [cross-phase roadmap](../../ROADMAP.md)（浏览第 8 阶段完整课程列表或跨阶段路线图）。
