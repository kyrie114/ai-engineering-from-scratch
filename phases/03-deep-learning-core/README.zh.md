# 第 3 阶段：深度学习核心（Phase 3: Deep Learning Core）

> 从第一性原理构建神经网络。在亲手实现一个之前，不使用任何框架。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 第 1 阶段"线性代数直觉"。推荐先完成第 2 阶段，以掌握模型评估相关的术语。

**第一课：** [感知机（The Perceptron）](01-the-perceptron/)

在仓库根目录运行这条命令：

```bash
python3 phases/03-deep-learning-core/01-the-perceptron/code/perceptron.py
```

请记下这条命令、退出码、各逻辑门的收敛结果、单个感知机在 XOR 上的失败表现，以及最终两层网络对 XOR 的预测输出。

**下一步：** 解释为什么一条线性边界无法解决 XOR，然后继续学习[多层网络与前向传播（Multi-Layer Networks and Forward Pass）](02-multi-layer-networks/)。
