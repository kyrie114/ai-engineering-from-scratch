# 阶段 0：环境搭建与工具（Phase 0: Setup & Tooling）

> 为后续的一切准备好你的环境。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 无。你需要 Git 以及 Python 3.11 或更新版本才能开始。其他工具只在你所选的学习路线需要时才安装。

**第一课：** [开发环境](01-dev-environment/)

在仓库根目录下，运行针对所选学习路线的预检：

```bash
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

请保留好命令本身、仓库根目录这一工作目录、退出码、必需检查项的结果，以及打印出来的 `Next:` 命令。可选检查项未通过并不算失败。

**下一步操作：** 修复所有必需检查项的失败，重新运行直到命令以 0 退出，然后继续学习 [Git 与协作](02-git-and-collaboration/)。

浏览 [Phase 0 完整课程列表](../../README.md#phase-0)或[跨阶段路线图](../../ROADMAP.md)。
