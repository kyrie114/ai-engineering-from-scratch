# Phase 10: LLMs from Scratch（从零实现大语言模型）

> 构建、训练，并真正理解大语言模型。

## Start this phase on GitHub

**Prerequisites:** Phase 5 NLP Foundations（第 5 阶段 NLP 基础）。强烈建议在进入模型构建课之前先学完 Phase 7 Transformers（第 7 阶段 Transformer）。

**First lesson:** [Tokenizers（分词器）](01-tokenizers/)

从仓库根目录运行以下命令：

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

保留命令、退出码、encode/decode 往返结果、学到的 merge 次数，以及压缩比。`tiktoken` 可作为可选对照。

**Next action:** 加一个小语料里没出现过的词，观察它被切成哪些片段，然后继续 [Building a Tokenizer from Scratch（从零构建分词器）](02-building-a-tokenizer/)。
