# 第 1 阶段：数学基础（Phase 1: Math Foundations）

> 每个 AI 算法背后的直觉，来自代码，而非教科书。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 完成第 0 阶段，或确认在仓库根目录下 Python 3.11+ 和 Git 都能正常工作。

**第一课：**[线性代数直觉](01-linear-algebra-intuition/)

在仓库根目录下运行以下命令：

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

请保留命令、退出码、归一化向量的输出、投影残差，以及一句解释"矩阵-向量乘积为什么就是一个神经网络层"的话。

**下一步操作：**修改其中一个输入向量，先预测结果，再运行一次，然后继续学习[向量、矩阵与运算](02-vectors-matrices-operations/)。
