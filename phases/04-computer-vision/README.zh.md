# 第 4 阶段：计算机视觉（Phase 4: Computer Vision）

> 从像素出发，跨越图像、视频与 3D，走向理解。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** Phase 1 Lesson 12, Tensor Operations, and Phase 3 Lesson 11,
Introduction to PyTorch. The first demo needs only NumPy.

**第一课：** [图像基础](01-image-fundamentals/)

在仓库根目录运行这条命令：

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

请记下命令本身、退出码、HWC 与 CHW 形状、归一化后的通道统计量、往返像素差以及插值粗糙度。该演示生成一张确定性的合成图像，不使用网络。

**下一步：** 解释 HWC 与 CHW 之间是哪个轴发生了变化，然后继续学习[从零实现卷积](02-convolutions-from-scratch/)。
