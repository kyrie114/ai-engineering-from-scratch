## 五、阶段 deck(v2)生成体系

**入口**:`phases/index.html`(导航)→ 每阶段一份独立 deck(11-13 页,瑞士 IKB,含演讲备注)。

**结构(按课数自适应)**:
- ≤12 课(00, 09):11 页;13-24 课:12 页;25-42+ 课:13 页(课单占 3 页,>36 课时尾页注「+N MORE」)
- 页序:封面 S01 → 论点 S09 → KPI 塔 S06 → 课单矩阵 S15×N → 四块基石 S19 → Build/Use 对照 S08 → 精选三课 S13 → 一课五步 S11 → 阶段资产账单 S20 → 阶段信条 S12 → 收束 S10
- 每页 data-layout + data-slide-id(pNN-*)+ 演讲备注;每份 deck 通过 validate-swiss-deck + validate-presenter-mode(20/20 全绿)

**数据管线**(`_gen_phase_decks.mjs` + `_phase_copy.mjs`):
- 课名/类型/语言/数量/tagline:解析 README Contents 区(### Phase 0 与 `<details id="phase-N">` 两种格式)
- 每课 enrich:docs/en.md 的标题/hook/`**Time:**`(真实时长)、quiz.json(兼容顶层数组与 {questions[]} 两种 schema)、outputs/ 文件数
- 阶段汇总:小时数=docs Time 逐课合计(**与 README 的 ~329h 口径不同,账单页已注明**;phase 19 的 600h 是 17 个 25-40h 毕业项目所致);5 个阶段(06/08/09/12/15)无 quiz.json,如实显示「—」
- 阶段级中文文案(论点/四基石/Build-Use/信条/收束)在 `_phase_copy.mjs`,人工撰写;课名与 hook 一律取自仓库

**重新生成**:`node _gen_phase_decks.mjs`(可选 `--only=NN` 单独重建某阶段);模板取自 guizang-ppt-skill 的 template-swiss.html,JS 引擎零改动,motion.min.js 共用 `../../assets/`。

**踩过的坑(已修)**:行内 span 宽度不生效需 display:block;bash 双引号转义会吃掉正则的 `\s\d`(用 Edit 工具改);对整个 markdown 跑数字正则会误抓正文(先锁 `**Time:**` 行);`+hr[1]+hr[2]` 字符串拼接导致 26,588h 离群值。
